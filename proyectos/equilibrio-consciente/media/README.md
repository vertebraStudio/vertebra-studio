# Imágenes necesarias para Equilibrio Consciente

Este directorio debe contener las siguientes imágenes:

1. **equilibrio-consciente-logo.png** - Logo o identidad visual del proyecto Equilibrio Consciente
2. **equilibrio-consciente-portatil.png** - Captura o mockup de la web en un portátil/dispositivo

Estas imágenes se utilizan en:
- La página del proyecto (`equilibrio-consciente.html`)
- La tarjeta del proyecto en la página principal (`index.html`)
